# Звук на проверку на слух

Генерируется `scripts/generate_audio.py`. Здесь то, что озвучено синтезом и может быть прочитано неверно:
нейтральный тон по отдельному иероглифу и слова с многозвучными иероглифами.

| Что | Иероглифы | Источник | Что проверить |
|---|---|---|---|
| слог ba5 | 吧 | TTS женский | нейтральный тон по иероглифу |
| слог ma5 | 吗 | TTS женский | нейтральный тон по иероглифу |
| слово 不 (w-bu) | многозвучные: 不 | TTS оба голоса + носитель | проверить чтение |
| слово 不是 (w-bushi) | многозвучные: 不 | TTS оба голоса + носитель | проверить чтение |
| слово 不要 (w-buyao) | многозвучные: 不要 | TTS оба голоса + носитель | проверить чтение |
| слово 工作 (w-gongzuo) | многозвучные: 作 | TTS оба голоса + носитель | проверить чтение |
| слово 很好 (w-henhao) | многозвучные: 好 | TTS оба голоса | проверить чтение |
| слово 你好 (w-nihao) | многозвучные: 好 | TTS оба голоса | проверить чтение |
| слово 一 (w-yi) | многозвучные: 一 | TTS оба голоса + носитель | проверить чтение |
| слово 一个 (w-yige) | многозвучные: 一 | TTS оба голоса | проверить чтение |
| слово 一天 (w-yitian) | многозвучные: 一 | TTS оба голоса | проверить чтение |
| слово 中国 (w-zhongguo) | многозвучные: 中 | TTS оба голоса | проверить чтение |
