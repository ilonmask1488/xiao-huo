# Аудит понятности интерфейса (UX §8)

Проверка по `docs/UX.md` §8: сброшен прогресс, пройден путь новичка через Playwright на вьюпорте iPhone 15
(WebKit): первый запуск → «Сегодня» → занятие целиком (урок, разминка-игра, «Повтори за диктором») →
«Курс» → «Тренировка» → «Словарь» → «Профиль». Скриншоты — `docs/screens/audit/` (снимаются командой
`SCREENS=audit npx playwright test screens --project=iphone`), «было» — `docs/screens/phase5/` (до UX-работ),
«стало» после шагов 1–3 — `docs/screens/ux1/`, `ux2/`, `ux3/`.

Для каждого экрана — три вопроса из §1.1: **где я? · что от меня требуется? · что будет, когда я нажму?**

## 3. Найдено на шаге 4 и исправлено

- Настройки: «Длительность пуска» → «Длительность занятия»; «Целевое удержание» → «Сколько слов помнить (удержание)».
- «Эхо»: подпись начиналась с термина «Шэдоуинг» → «Слушай и повторяй вслух в паузу (это называется шэдоуинг)».
- Итоги игры: «Δv +1 м/с» → «Очки +1». Итоги урока: «Вслух» → «Сказано вслух».
- Тренажёр тонов: у примеров 妈 / 麻 / 马 / 骂 / 吗 не было перевода — добавлен; сверху — пояснение цветов пиньиня по тапу.
- «Послушай серию»: у слов в серии не было перевода — добавлен под пиньинем.
- Диалог: у вариантов ответа не было пути к переводу — «Подсказка: перевод» показывает перевод под каждым вариантом.
- Карточка слова: уровень «HSK 3.0 · 1» объясняется тапом.
- «Занятие на сегодня»: «· 2 мин» переносилось на новую строку — теперь не переносится.

## 4. Перевод в один тап — где есть китайский текст

| Место | Как получить перевод |
|---|---|
| Фраза в упражнениях «Разбери фразу», «Собери фразу», «Скажи по-китайски», «Повтори вслух», «Прочитай вслух», объяснения | Перевод фразы под ней; тап по слову — лист слова |
| Крупное слово в «Повтори вслух», «Прочитай вслух», «Скажи по-китайски» | Перевод виден или «Подсказка: перевод»; тап по слову — лист |
| «Что это значит?» (на слух / по тексту) | Перевод — сам ответ; после ответа показан верный |
| Карточки повторения | Перевод — ответ; «Проверить себя» открывает; тип 3 показывает перевод в задании |
| Реплика собеседника в диалоге | Перевод под репликой (можно скрыть); тап по слову — лист |
| Варианты ответа в диалоге | «Подсказка: перевод» под вариантами; после ответа — перевод выбранного и верного |
| «Послушай серию» | Слова — с переводом; слоги (mā, mà) переводов не имеют |
| Слова в объяснениях (WordLine), словарь, карточка слова, этап курса | Перевод рядом |
| «Эхо» | Переключатель перевода на дорожке |
| Тренажёр тонов | Перевод под примером; ячейка тепловой карты открывает слово с переводом |
| Игры («Скорострел», «Сборка», «Близнецы») | «Скорострел» — перевод в вариантах; «Сборка» — перевод фразы сверху; слоги переводов не имеют |
| Персонажи сюжета, маскот | Имя по-русски рядом |

## 5. Автотесты

- `e2e/exercises.spec.ts`: проходит уроки 0.1.1, 0.2.1, 0.4.1, 1.1.2, босса 1.1 и карточки повторения; на каждом
  экране упражнения проверяет инструкцию, строку шагов и кнопку «?», а в конце — что встретились все 13 инструкций.

- `e2e/welcome.spec.ts`: первый запуск, «Что изменилось», «Показать обучение заново», термины по тапу.
- `e2e/screens.spec.ts`: `SCREENS=audit` — прогулка новичка (44 экрана), `SCREENS=ux3` — экраны шага 3.
