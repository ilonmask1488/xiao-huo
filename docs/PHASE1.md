Основное ТЗ — `docs/SPEC.md`, этот файл его уточняет. При противоречии прав этот файл. Положи его в `docs/PHASE1.md`.

## 0. Где мы сейчас

Фаза 0 принята: оболочка, навигация, база, PWA, деплой, тесты — всё работает.

Пользователь открыл приложение и увидел, что:
- «Начать пуск» ведёт на заглушку;
- звука нет;
- карта полёта — просто картинка;
- тепловая карта тоновых пар выглядит как неработающий элемент (непонятно, что это и что нажимать);
- словарь пуст.

**Цель фазы 1:** после неё пользователь каждый день занимается тонами и звуками со звуком, это весело, и он видит свой прогресс.

**Главный принцип порядка работы:** пользователь должен начать заниматься как можно раньше. Поэтому сначала звук и первый урок с деплоем, потом всё остальное.

## 2. Шаг 1 — Звук (самое важное)

### 2.1. Записи слогов носителями

1. Найди открытый набор записей слогов путунхуа с тонами (например, проверь `hugolpz/audio-cmn` на GitHub и аналоги).
2. **Прежде чем использовать, отчитайся пользователю:** название, ссылка, лицензия, сколько слогов покрыто, качество (послушай несколько, проверь громкость и тишину по краям). Жди подтверждения.
3. Если подходящего набора нет — сообщи и перейди к п. 2.2, генерируя слоги через TTS по заранее подобранным иероглифам. Каждому слогу с тоном — однозначный иероглиф (не многозвучный), список положи в `scripts/syllable_chars.json` и пометь `reviewed: false`.
4. Нормализуй громкость, обрежь тишину, конвертируй в единый формат (opus или mp3, моно). Скрипт `scripts/prepare_syllables.py`.
5. Все файлы, источники и лицензии — в `public/audio/manifest.json`. Атрибуция — на экране «О приложении» и в README.

### 2.2. Озвучка слов и фраз

- Скрипт `scripts/generate_audio.py` на `edge-tts`: женский голос `zh-CN-XiaoxiaoNeural`, мужской `zh-CN-YunxiNeural`. Кэш по хэшу (текст + голос + скорость).
- Скрипт запускается на компьютере пользователя (Россия). Если сервис недоступен — сообщи пользователю и предложи варианты, не молчи.
- Для каждого слова — оба голоса: разные голоса помогают слышать тон, а не тембр.

### 2.3. Воспроизведение (`src/lib/audio/`)

- Единый плеер: одновременно играет только один звук; предзагрузка следующих 3–5 файлов.
- iOS: разблокировка аудио на первом касании. **Проверить в e2e на WebKit**, что звук реально запускается (хотя бы что `play()` не отклоняется).
- Если файла нет — запасной `speechSynthesis` с `zh-CN`. Если нет и китайского голоса — понятная подсказка, как его установить.
- Ошибки — понятным русским текстом с действием («Проверь, не включён ли беззвучный режим»).

### 2.4. Проверка звука

Экран «Проверка звука» (в «Ещё» и при первом запуске урока): кнопка «Послушать mā má mǎ mà», подсказки для беззвучного режима iPhone.

## 3. Шаг 2 — Первый урок и первый деплой

Сделай **этап 0.1 «Четыре тона и нейтральный» целиком**, подключи его к «Пуску» и карте, задеплой и сообщи пользователю, что можно начинать. Остальное — после.

### 3.1. Из чего состоит урок

Урок — последовательность коротких экранов, 10–15 минут. Типы экранов (переиспользуются во всех этапах):

| Тип | Что делает пользователь |
|---|---|
| Объяснение | Читает 2–4 предложения + график тона + кнопки прослушивания. Никаких «стен текста» |
| Послушай | Слушает серию (mā má mǎ mà), может повторять |
| Повтори вслух | Слушает → пауза «твоя очередь» (длина образца × 1.5) → снова образец. Самооценка: «получилось / не очень» |
| Угадай тон | Звучит слог → выбрать тон (кнопки с мини-графиками) |
| Какой слог? | Звучит слог → выбрать из 2–4 вариантов пиньиня (минимальные пары) |
| Прочитай | Показан пиньинь со знаком тона → сначала сказать вслух, потом проверить по образцу |

Правила:
- Не больше 3 экранов одного типа подряд.
- После ошибки — сразу прослушать оба варианта: «ты выбрал 2-й, а это был 3-й», с кнопками «послушать оба».
- Ответы пишутся в базу (для статистики и тепловой карты).
- Прогресс внутри урока сохраняется: можно выйти и продолжить.
- В конце — итоги: время, точность, Δv, реплика маскота.

### 3.2. Содержание этапа 0.1

1. Что такое тоны: одна последовательность звуков с разным тоном — разные слова (妈 / 麻 / 马 / 骂 / 吗).
2. Каждый тон отдельно: график по шкале Чао + как это ощущается по-русски:
   - 1-й — ровно и высоко, как будто поёшь ноту;
   - 2-й — вверх, как удивлённое «а?»;
   - 3-й — низко, с «ямкой», в быстрой речи часто просто низкий;
   - 4-й — резко вниз, как уверенное «да!» или «стоп!»;
   - нейтральный — коротко и легко.
3. Серии для прослушивания и повторения: ma, ba, yi, wu, da.
4. «Угадай тон»: сначала из 2 вариантов (1 vs 4, 2 vs 3 — самые разные и самые путаемые), потом из 4.
5. Предупреждение, специфичное для русскоязычных: не накладывай интонацию вопроса или восклицания на тоны; 3-й тон тянут вверх слишком сильно.
6. Первые слова (чтобы словарь начал наполняться): 你好 nǐ hǎo, 谢谢 xièxie, 再见 zàijiàn, 我 wǒ, 你 nǐ, 是 shì, 不 bù.

### 3.3. «Пуск» в фазе 1

Пока нет повторения FSRS (фаза 2), «Пуск» собирается из того, что есть:
- Разминка — мини-игра (когда появится; до этого — «Угадай тон» из пройденного).
- Новое — следующий урок текущего этапа.
- Эхо — «Повтори вслух» по пройденному материалу.
- Блоки без содержания пропускаются. Занятие короче 40 минут — это нормально; в итогах честно: «Сегодня 18 минут — пока это всё, что есть на стартовом столе».

## 4. Шаг 3 — Остальная ступень 0

### 4.1. Этапы

**0.2 Финали.** Простые (a o e i u ü), сложные (ai ei ao ou, ia ie iao iu, ua uo uai ui, üe), носовые (an en ang eng ong, in ing, ian iang iong, uan un uang, üan ün), er. Отдельно: e не похоже на русское «е»; ü в ju / qu / xu / yu пишется без точек; -i после z / c / s и zh / ch / sh / r — особые звуки, не «и».

**0.3 Инициали** — группами: b p m f · d t n l · g k h · j q x · zh ch sh r · z c s. Главный акцент — придыхание (объяснить через «ладонь у рта / листок бумаги»).

Минимальные пары для «Какой слог?» (дополни, каждую проверь):

| Контраст | Пара |
|---|---|
| b / p | 爸 bà — 怕 pà |
| d / t | 肚 dù — 兔 tù |
| g / k | 哥 gē — 科 kē |
| z / c | 在 zài — 菜 cài |
| zh / ch | 知 zhī — 吃 chī |
| j / q | 鸡 jī — 七 qī |
| zh / z | 找 zhǎo — 早 zǎo |
| ch / c | 出 chū — 粗 cū |
| sh / s | 是 shì — 四 sì |
| zh / j | 知 zhī — 鸡 jī |
| sh / x | 师 shī — 西 xī |
| r / l | 热 rè — 乐 lè |

| -n / -ng | 山 shān — 商 shāng; 心 xīn — 星 xīng |

**0.4 Тоновые пары** — все 20 сочетаний на реальных словах:

| | +1 | +2 | +3 | +4 | +нейтр. |
|---|---|---|---|---|---|
| **1** | 飞机 fēijī | 中国 Zhōngguó | 铅笔 qiānbǐ | 工作 gōngzuò | 桌子 zhuōzi |
| **2** | 明天 míngtiān | 学习 xuéxí | 词典 cídiǎn | 同事 tóngshì | 朋友 péngyou |
| **3** | 老师 lǎoshī | 美国 Měiguó | 你好 nǐ hǎo* | 考试 kǎoshì | 我们 wǒmen |
| **4** | 汽车 qìchē | 问题 wèntí | 电脑 diànnǎo | 再见 zàijiàn | 谢谢 xièxie |

\* звучит как ní hǎo — подводка к этапу 0.5.

**0.5 Сандхи.** 3+3 → 2+3 (你好, 很好 hěn hǎo, 可以 kěyǐ); 不 перед 4-м → bú (不是, 不要 búyào); 一: yī / yí / yì (一, 一个 yí ge, 一天 yì tiān). Показ «словарный пиньинь → как звучит» из модуля `pinyin`. Логику сандхи вынести в `src/lib/pinyin/sandhi.ts` с тестами.

**0.6 «Предстартовый тест» — босс ступени.** 3–4 минуты: смесь всех типов, итог по тонам, инициалям и финалям. Успех (≥ 80 %) — анимация пуска ракеты и сборка первой части ракеты на карте. Неудача — «пуск перенесён», показ слабых мест, кнопка «ещё раз» и тренировка именно слабых мест. Никаких штрафов.

### 4.2. Мини-игры

Общие правила: 60–90 секунд, личный рекорд, комбо-множитель (×2 после 5 подряд, ×3 после 10), приятные звуки (выключаемые), вибрация на Android. Все используют только пройденный материал. Ошибка не заканчивает игру, а сбрасывает комбо.

1. **«Тон-тир».** Звучит слог → свайп по направлению тона (→ ↗ ∨ ↘, тап — нейтральный) **или** одна из 5 кнопок (для ПК и для тех, кому неудобны свайпы). Темп растёт с серией верных ответов. После раунда — «твой самый трудный тон сегодня: 3-й» + кнопка потренировать его.
2. **«Пинг-понг пар».** Звучит двусложное слово из 0.4 → выбрать пару тонов. Слабые пары (по статистике) выпадают чаще.
3. **«Близнецы».** Минимальные пары из 0.3: что прозвучало?

### 4.3. Тепловая карта тоновых пар

- Таблица 5×5 (первый слог × второй), цвет ячейки = доля ошибок, в ячейке пример слова.
- Нажатие на ячейку → пример слова со звуком + «Потренировать эту пару» (запускает «Пинг-понг» с упором на неё).
- Легенда и одна строка объяснения: «Чем краснее, тем чаще ошибаешься». Пустое состояние — см. п. 1.
- Данные — из ответов в уроках и играх (новая версия схемы БД + миграция + тест).

### 4.4. Карта полёта

- Ступени раскрываются в список этапов; этап — кнопка: открыть, продолжить, пройти заново; показан прогресс (например, «3 из 5 уроков»).
- Ракета собирается по прогрессу: пройденная ступень рисуется сплошной, текущая — частично, будущие — пунктиром.
- Этапы следующих ступеней, которых ещё нет в данных, показаны как «готовится», без кнопок.

### 4.5. Словарь

Наполняется словами из пройденных уроков: иероглифы, пиньинь с цветом тонов, «как звучит» (если сандхи), перевод, звук в двух голосах. Поиск по пиньиню с тонами и без, цифрами и значками.

### 4.6. Прогресс и мотивация (перенос части фазы 2)

Чтобы уже сейчас было ради чего заходить:
- Δv за уроки и игры (формула в одном месте, легко менять);
- «дней на орбите» — день засчитывается при ≥ 10 минутах занятий;
- 5–7 достижений ступени 0 (например, «Первый 你好», «Ямка покорена» — 50 верных третьих тонов, «Близнецы различены», «Стартовый стол пройден»).

Названия и реплики — в `src/i18n/ru.ts`, добрые и смешные. Пул реплик маскота для уроков — 30+.

## 8. Критерии приёмки фазы 1

- Нажимаю «Начать пуск» — получаю занятие со звуком, без заглушек.

- Все проверки зелёные: `npm test`, `npm run check:content`, `npm run e2e`, `npm run build`.
