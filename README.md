# 小火 · Сяо Хо — разговорный китайский

Приложение для ежедневной тренировки разговорного китайского: тоны, произношение, слова, фразы, шэдоуинг, сюжетные диалоги.
Работает в браузере телефона, ставится на главный экран как обычное приложение и работает без интернета.
Без аккаунтов, рекламы и аналитики: прогресс хранится только на твоём устройстве.

Техническое задание — [docs/SPEC.md](docs/SPEC.md), уточнения фазы 1 — [docs/PHASE1.md](docs/PHASE1.md).

Готово:
- **Фаза 1 — «Стартовый стол»**: вся ступень 0 (6 этапов, 14 уроков со звуком, предстартовый тест), мини-игры «Тон-тир», «Пинг-понг пар», «Близнецы», тепловая карта тоновых пар.
- **Фаза 2 — «Первая ступень»**: HSK 1 — 9 этапов, 27 уроков, 139 слов, 112 фраз с грамматикой; интервальное повторение FSRS (карточки: на слух → значение, иероглифы → значение, «скажи вслух», тоны); ежедневный «Пуск» из кусков не длиннее ~3 минут одного формата; игры «Скорострел» и «Сборка»; статистика с прогнозом до HSK; кнопка «Потренироваться с Claude».
- **Фаза 3 — «Эхо и сюжет»**: каждый этап ступени 1 заканчивается диалогом-боссом (реплики персонажей их голосами, свои ответы выбираешь и говоришь вслух; от 80% — анимация пуска); плеер «Эхо» для шэдоуинга (0.75/1.0, автопауза «время фразы × 1,2», повтор, иероглифы/пиньинь/перевод, «только звук»); запись своего голоса и сравнение «образец → я → образец» в «Эхо», диалогах, «Повтори» и «Скажи сам»; «Командировка» — эпизоды 1–4 с культурными вставками.
- **Фаза 4 — «Произношение и иероглифы»**: график высоты тона — твоя запись и образец двумя линиями (в полутонах от медианы голоса, чтобы мужской и женский голос были сравнимы); распознавание речи (бета, только где браузер умеет); вторая ступень — HSK 2 и базовый модуль «Инженер» (12 этапов, 48 уроков, 184 слова, диалоги-боссы); карточка слова с порядком черт (анимация и «напиши сам») и мнемониками; карточки FSRS типа 5 «только иероглифы».
- **Фаза 5 — «Выход на орбиту»**: третья ступень — HSK 3 целиком (14 этапов, 56 уроков, 361 слово, 418 фраз, диалоги-боссы) и три этапа расширенного «Инженера» (совещание и планы, материалы и производство, испытания и качество); эпизоды «Командировки» 5–8 (экскурсия по заводу, совещание, испытания, прощальный ужин и 干杯); достижения за каждую ступень и «На орбите» за весь курс; контент вынесен из основного бандла (182 КБ gzip вместо 313). Словарь курса — 721 слово: HSK 1–3 полностью и 94 слова модуля «Инженер».

## 1. Что нужно установить (один раз)

Понадобятся три программы: **Node.js LTS** (собирает и запускает приложение), **Git** (хранит историю и публикует на GitHub) и **Python 3** (нужен с фазы 1 для генерации аудио).

### Windows (PowerShell)

Открой PowerShell (Пуск → «PowerShell») и выполни:

```powershell
winget install OpenJS.NodeJS.LTS
winget install Git.Git
winget install Python.Python.3.12
```

Закрой PowerShell и открой заново, чтобы новые команды стали видны. Проверка:

```powershell
node -v
git --version
python --version
```

### macOS

```bash
brew install node git python
```

Если нет Homebrew, установи его с [brew.sh](https://brew.sh) или скачай установщики с nodejs.org, git-scm.com и python.org.

### Linux (Ubuntu/Debian)

```bash
sudo apt install git python3
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt install nodejs
```

## 2. Первый запуск на компьютере

```powershell
cd путь\к\папке\xiao-huo
npm install
npm run dev
```

Открой в браузере адрес, который покажет команда (обычно http://localhost:5173). Остановить — `Ctrl+C`.

## 3. Посмотреть на телефоне в той же Wi-Fi сети

```powershell
npm run dev -- --host
```

Команда покажет строку `Network: http://192.168.x.x:5173` — открой этот адрес в браузере телефона. Телефон и компьютер должны быть в одной сети. Если Windows спросит про брандмауэр, разреши доступ **для частных сетей**.

> ⚠️ Так приложение открывается по обычному `http://`, а браузеры разрешают установку на главный экран, офлайн-режим и микрофон только на `https://`. Поэтому по Wi-Fi удобно смотреть вёрстку, а «настоящее» приложение живёт на GitHub Pages (раздел 5).

## 4. Проверки

```powershell
npm test                   # юнит-тесты: пиньинь, база, миграции, бэкап, раскладка занятия
npm run check:content      # контроль качества учебного контента
npx playwright install chromium webkit   # один раз: браузеры для e2e (~250 МБ)
npm run e2e                # сквозные тесты на вьюпортах Android и iPhone
npm run build              # сборка в папку dist
```

Скриншоты экранов для проверки дизайна: `$env:SCREENS='phase0'; npx playwright test screens` (Windows) или `SCREENS=phase0 npx playwright test screens` (macOS/Linux) — картинки появятся в `docs/screens/phase0/`.

## 4а. Звук

Готовые файлы уже лежат в `public/audio` — пересоздавать их нужно, только когда меняется учебный контент.

- **Слоги с тонами 1–4 и слова** — записи носителей из открытого набора [hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn) (лицензия CC BY-SA, дикторы Chen Wang и Yue Tan). Скрипт обрезает тишину и выравнивает громкость.
- **Нейтральный тон и все слова ещё в двух голосах** — синтез `edge-tts` (женский Xiaoxiao, мужской Yunxi). У персонажей диалогов свои голоса: Xiaoyi (официантка), Yunjian (таксист; и «ты», если в настройках мужской голос), Yunyang (инженер Ван). Это неофициальный доступ к сервису Microsoft для личного использования; интернет нужен **только при сборке звука**, приложению — нет.
- Что синтез мог прочитать неверно (многозвучные иероглифы, нейтральный тон по одному иероглифу), скрипт выписывает в `docs/audio-review.md` — это стоит послушать.

Один раз подготовить окружение (Windows):

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r scripts\requirements.txt
```

Пересоздать звук:

```powershell
.venv\Scripts\python.exe scripts\generate_audio.py
npm run check:content
```

На macOS/Linux то же самое через `python3 -m venv .venv` и `.venv/bin/python`. Если `edge-tts` не отвечает (сервис Microsoft бывает недоступен из России), скрипт напишет об этом — попробуй позже, из другой сети или через VPN.

## 5. Публикация на GitHub Pages (постоянный адрес с https)

Один раз:

1. Заведи аккаунт на [github.com](https://github.com), если его нет.
2. Создай **новый пустой** репозиторий (кнопка «New»), например `xiao-huo`. Галочки «Add README» и прочие не ставь.
3. В папке проекта выполни (подставь свой логин):
   ```powershell
   git remote add origin https://github.com/ЛОГИН/xiao-huo.git
   git push -u origin main
   ```
   Git попросит войти в GitHub — откроется окно браузера.
4. На GitHub: репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. Вкладка **Actions** покажет запуск «Проверка и публикация». Когда он станет зелёным (5–10 минут), приложение будет доступно по адресу `https://ЛОГИН.github.io/xiao-huo/`.

Дальше каждое `git push` в ветку `main` сам прогоняет тесты и, если они зелёные, обновляет сайт.

> Если назовёшь репозиторий `ЛОГИН.github.io`, сайт будет в корне домена; тогда в `.github/workflows/deploy.yml` замени `BASE_PATH: /${{ github.event.repository.name }}/` на `BASE_PATH: /`.

> ⚠️ **Доступность из России.** GitHub Pages (`*.github.io`) обычно открывается, но бывают перебои у отдельных провайдеров. После публикации открой адрес **с телефона через мобильный интернет и через домашний Wi-Fi**. Установленному приложению сеть нужна только для обновлений: оно работает офлайн.

## 6. Установка на телефон

Открой адрес с GitHub Pages:

- **Android (Chrome):** на главном экране приложения появится кнопка «Установить», либо меню ⋮ → «Установить приложение».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“». **Обязательно установи:** Safari стирает данные сайтов, которые не открывались 7 дней и не установлены на главный экран.

## 7. Как проверить на телефоне

1. Открой приложение, установи его на главный экран, запусти с иконки-ракеты. Если приложение уже стояло — нажми «Обновить», когда появится «Готова новая версия».
2. «Начать пуск» → «Начать: Новое». Перед первым уроком — проверка звука. Пройди урок до итогов, говоря вслух на экранах «Повтори» и «Прочитай».
3. Вернись в «Пуск»: открылись «Разминка» (минута «Тон-тира») и «Эхо».
4. «Карта»: ступень 0 раскрыта по этапам 0.1–0.6, у каждого урока «Открыть / Продолжить / Пройти заново». Кнопка «Скачать звук ступени для офлайна» — после неё уроки звучат в режиме полёта.
5. «Тоны»: у каждого тона кнопка звука; мини-игры открываются по мере прохождения. После «Пинг-понга пар» заполняется тепловая карта — нажми на ячейку.
6. «Словарь»: слова появляются после урока «Нейтральный тон и первые слова»; поиск понимает «nihao», «ni3hao3», «nǐ hǎo» и «привет».
7. Этап 0.6 «Предстартовый тест»: от 80% — анимация пуска и готовая часть ракеты на карте, меньше — «пуск перенесён» и тренировка слабого места.
8. «Ещё → Настройки»: тема, длительность, бэкап — как в фазе 0.
9. **Фаза 2.** «Пуск» теперь — циклограмма из кусков по 2–3 минуты: разминка-игра, повторение карточек, новый урок, эхо, «скажи сам». Карточки: «Показать ответ» → «Снова / Трудно / Хорошо / Легко» (под кнопкой — через сколько карточка вернётся).
10. «Карта» → ступень 1 → этап → «Слова, фразы и грамматика»: списки и кнопка «Потренироваться с Claude» — промпт копируется, вставь его в чат с Claude.
11. «Ещё → Статистика»: минуты по дням, удержание, трудные пары, прогноз до HSK 1/2/3 (шкала — в настройках).
12. **Фаза 3.** «Карта» → этап 1.1 → последний урок «Обратный отсчёт»: диалог с Сяо Ли. Реплики звучат голосами персонажей, на своих — выбери ответ и скажи его вслух; «Записать себя» → «Понятно, записать» (в первый раз браузер спросит микрофон) → «Стоп» → услышишь образец, себя и снова образец. От 80% верных — «Пуск!», меньше — «Пуск перенесён» и кнопка «Послушать диалог в «Эхо»».
13. **Запись на iPhone проверь обязательно**: в автотестах её можно проверить только в Chrome. Если в Safari запись не звучит при сравнении — напиши, это чинится отдельно.
14. «Ещё → Эхо»: дорожки пройденного (фразы этапа, диалог, эпизоды). «Играть» — фраза, полоска «Твоя очередь», следующая; скорость 0.75×, переключатели иероглифов/пиньиня/перевода, «Только звук».
15. «Ещё → Командировка»: эпизоды 1–4 советуют после этапов 1.1, 1.7, 1.9 и 1.6 (смотреть можно и раньше); в конце эпизода — культурная вставка, внизу — персонажи.
16. **Фаза 4.** После записи в «Эхо» или в диалоге нажми «График тона»: сплошная линия — образец, пунктир — ты. Сравнивай форму (где голос идёт вверх, где вниз), а не точное совпадение — это подсказка, а не оценка.
17. «Распознать (бета)» — видно только там, где браузер умеет распознавать речь (обычно Chrome на Android). Звук уходит серверам разработчика браузера, тоны напрямую не проверяются — сравниваются только иероглифы.
18. «Словарь» → нажми на иероглиф → карточка слова: «Как запомнить», «Как писать» (анимация порядка черт и «Напиши сам» — веди пальцем), примеры, «Добавить в повторение». Фильтры словаря: ступень, HSK, «Инженер», «Трудные».
19. «Карта» → «Вторая ступень»: 12 этапов, из них три — «Инженер» (завод и чертёж, размеры и допуски, ракета и испытания). После первого урока второй ступени в повторении появятся карточки «только иероглифы» (включить раньше — «Настройки»).
20. **Фаза 5.** «Карта» → «Выход на орбиту»: 14 этапов, последние три — «Инженер». Последний урок курса — «Обратный отсчёт: Огневые испытания: пуск»; после него — достижение «На орбите». Ступени 1 и 2 тоже дают достижение, когда закрыты все их этапы.
21. «Ещё → Командировка»: эпизоды 5–8 советуют после этапов 2.4, 3.12 и 3.14. В эпизоде 6 тебя представляют заказчику — там же фразы «повторите, пожалуйста» и «говорите медленнее».
22. «Ещё → Статистика» → «Прогноз до HSK»: строка HSK 3 теперь считает настоящие слова третьей ступени.

## 7а. Как устроен контент ступени 1

Источник — `scripts/author_stage1.py`: слова с переводом, фразы с переводом и грамматика записаны там компактно. Скрипт разбивает фразы на слова по словарю курса, берёт уровни HSK из открытого списка [drkameleon/complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary) (MIT) и собирает по 3 урока на этап. После правки:

```powershell
.venv\Scripts\python.exe scripts\author_stage1.py
.venv\Scripts\python.exe scripts\generate_audio.py
npm run check:content
```

Сюжет «Командировки» — `scripts/author_story.py` (эпизоды, реплики, культурные вставки), персонажи и сборка диалогов — `scripts/content_lib.py`, диалоги-боссы этапов — в `author_stage1.py`. У реплик «ты» — верный ответ и 1–3 неподходящих по смыслу. `check:content` проверяет, что персонажи существуют, у каждого этапа ступени 1 последний урок — диалог-босс, а у каждой реплики есть звук голосом персонажа.

Ступени 2 и 3 — `scripts/author_stage2.py` и `scripts/author_stage3.py` в том же формате (этапы с `"engineering": True` — модуль «Инженер»; их профессиональные слова получают метку `engineering`). Мнемоники к словам — `scripts/mnemonics.py`. Данные порядка черт — `npm run hanzi`: копирует из `hanzi-writer-data` только иероглифы курса в `public/hanzi/`. После правки контента ступени 2:

```powershell
.venv\Scripts\python.exe scripts\author_stage2.py
.venv\Scripts\python.exe scripts\author_stage3.py
.venv\Scripts\python.exe scripts\author_story.py
.venv\Scripts\python.exe scripts\generate_audio.py
npm run hanzi
npm run check:content
```

Всё сгенерированное помечено `reviewed: false`; `check:content` сверяет пиньинь слов и целых фраз с pinyin-pro и выписывает расхождения.

## 8. Бэкап и перенос прогресса

Весь прогресс живёт только в браузере этого устройства. «Ещё → Настройки → Сохранить бэкап» сохраняет его одним JSON-файлом; «Загрузить бэкап» на другом устройстве переносит всё целиком. Раз в две недели приложение напомнит о бэкапе.

## 9. Обновление

- Код поменялся → `git push` → через несколько минут сайт обновлён. Установленное приложение покажет «Готова новая версия · Обновить».
- Прогресс при обновлении не теряется: схема базы версионируется, тест `src/lib/db/migrations.test.ts` проверяет, что данные каждой прошлой версии переживают обновление.
- Обновить библиотеки: `npm outdated`, затем `npm update` и прогнать все проверки из раздела 4.

## 10. Устройство проекта

```
src/app          оболочка, маршруты, навигация, первый запуск
src/features     экраны: session (главный, пуск), lesson (урок, его экраны, диалоги), games (мини-игры),
                 course (карта), tones (тоны, тепловая карта), echo (плеер «Эхо»), story (сюжет),
                 dictionary, settings, more
src/lib          audio (плеер, эффекты, запись голоса), echo (дорожки «Эха»), story (персонажи, эпизоды),
                 lesson (сборка урока, прогресс, «босс»), launch (ежедневный пуск),
                 srs (FSRS: карточки, очередь, открытие типов), games, claude (промпт для чата),
                 progress (Δv, дни на орбите, тепловая карта, достижения, статистика),
                 pinyin (знаки, поиск, сандхи), db (Dexie + схема), backup, settings, pwa
src/content      учебный контент: units, lessons, words (JSON) и их типы; stage1/, stage2/, stage3/ — ступени,
                 story/ — эпизоды, characters.json — персонажи (всё это генерируют скрипты);
                 data.ts склеивает JSON в отдельный кусок бандла, index.ts грузит его до первого рендера
src/i18n/ru.ts   все тексты интерфейса, метафоры, реплики маскота
src/styles       дизайн-токены (цвета тонов, темы), базовые стили
scripts          generate_audio.py (звук), author_stage1.py / author_story.py (контент), check_content.ts, audit_audio_cmn.py
e2e              сквозные тесты Playwright
public           иконки PWA (из icon.svg: `npm run icons`), public/audio — звук и манифест
docs             ТЗ, audio-review.md (звук на проверку на слух), скриншоты по фазам
```

Синтез — Microsoft Edge TTS (голоса Xiaoxiao, Yunxi, Xiaoyi, Yunjian, Yunyang), для личного использования. Полный список источников — в `public/audio/manifest.json` и на экране «О приложении».
